# ORBIT SHIFT

[ブラウザで遊ぶ](https://akira-motoyoshi.github.io/orbit-shift/)

GitHub Pages で公開しています。インストール不要です。

スペースキーひとつで内側と外側の軌道を切り替える、60秒のスコアアタックです。ミント色の点が自分、赤いブロックが障害物、光るひし形が回収アイテム。障害物は右側から画面上部の自分へ近づきます。

## 遊び方

- **スペース**またはゲーム画面の**クリック／タップ**：軌道を切り替えます。
- **Esc / P**：一時停止・再開。
- **M**または画面右上の音ボタン：音のオン・オフ。
- ライフは3つ。光を連続回収すると、6個ごとに倍率が上がり、最大5倍になります。光を逃すか、赤にぶつかるとコンボが切れます。
- 光は基本10点 × 倍率。障害物を通過すると5点。60秒完走で300点 + 残りライフ × 100点のボーナス。
- 自己ベストと音の設定はブラウザに保存します。オンライン版とオフライン版、異なるブラウザの記録は別々です。保存できない環境でもプレイできます。

`ORBIT-SHIFT.html` は単独で動くオフライン版です。Safari、Chrome、Edge、Firefoxなどの現在のブラウザで開いてください。追加ソフトや通信は必要ありません。

## 企画から完成までのフロー

1. **企画**：短時間で再挑戦できること、一操作で理解できること、容量と処理を軽くすることを基準に、2軌道・60秒・3ライフを選びました。
2. **プレイ設計**：光と障害物を反対の軌道に配置し、必ず逃げ道を作ります。最初の2配置は切り替えなしでも回収でき、20秒・40秒でテンポが上がります。
3. **実装**：Canvas 2D、標準JavaScript、CSSだけを使用。効果音と短いリズムはWeb Audioで合成し、画像・音声ファイル・外部ライブラリを使いません。
4. **調整**：切り替えの140ms補間、被弾後の猶予、コンボ演出、軌道の予告時間、再挑戦ボタンを調整しました。粒子数と同時障害物数を抑え、背景をキャッシュします。画面を隠したときは自動停止します。
5. **デバッグ**：300シードで無傷・全回収の完走を確認。15/30/60/144fps相当のゲームルールの検証、一時停止、衝突、取り逃し、重複加点、リセットを確認しました。UIコントローラーでも60秒完走、結果画面、保存不可環境、音声APIなし環境、単一描画ループを検証しました。
6. **実画面確認**：Codexのブラウザで開始、スペース操作、停止・再開、ゲームオーバー、再挑戦、音の切り替え、自己ベスト保存を確認しました。デスクトップ・狭い画面で表示を確認し、オフライン版を作成しました。自動確認ブラウザは file: URL を禁止しているため、オフラインファイルの直接起動は未検証です。埋め込まれたソースの一致と外部依存がないことは確認しています。

## ソースから実行する

外部パッケージのインストールは不要です。`dist/index.html` をブラウザで開くか、次のコマンドでローカル配信できます。

```sh
python3 -m http.server 8765 --directory dist
```

ゲームのルールとUIの回帰テストはNode.jsで実行できます。

```sh
node tests/game.test.cjs
node tests/ui-flow.test.cjs
```

オフライン版を再作成する場合：

```sh
python3 export.py ORBIT-SHIFT.html
```

ゲームのルールは `dist/game-core.js`、表示・入力・効果音は `dist/game.js`、レイアウトは `dist/style.css` に分かれています。
